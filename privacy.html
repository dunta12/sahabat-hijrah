Kebijakan Privasi — Sahabat Hijrah

Terakhir diperbarui: Agustus 2026

Sahabat Hijrah adalah aplikasi jadwal sholat, tasbih, dan alat ibadah yang bekerja sepenuhnya di perangkat Anda (offline).

1. Data yang dikumpulkan

Kami TIDAK mengumpulkan, menyimpan, atau mengirim data pribadi apa pun ke server. Tidak ada akun, tidak ada pelacakan, tidak ada analitik, dan tidak ada iklan pihak ketiga.

2. Penyimpanan lokal

Aplikasi hanya menyimpan pengaturan (kota, metode perhitungan, koreksi menit, jumlah tasbih) di penyimpanan lokal perangkat (localStorage). Data ini tidak pernah meninggalkan perangkat dan dapat dihapus kapan saja melalui pengaturan browser.

3. Izin lokasi (GPS)

Jika fitur GPS digunakan, koordinat dipakai HANYA di dalam perangkat untuk menghitung jadwal sholat. Koordinat tidak dikirim ke mana pun.

4. Suara & pengingat

Pengingat waktu sholat dibunyikan secara lokal oleh perangkat selama aplikasi terbuka. Tidak ada server notifikasi.

5. Keamanan

Karena tidak ada data yang dikirim atau disimpan di server, risiko kebocoran data sangat minim.

6. Perubahan kebijakan

Kebijakan ini dapat diperbarui sewaktu-waktu dan akan ditampilkan di halaman ini.
